Privacy

This site does not use cookies, does not ask you to sign in, and does not run advertising trackers.

Analytics

We count page views with Cloudflare Web Analytics. It is cookieless: it does not set cookies or use local storage to identify you, and it does not build a profile of you across sites. It records things like the page viewed, the referring site, browser type and country, in aggregate.

If your browser sends a Do Not Track signal, the analytics script is not loaded at all.

Hosting

The site is served by GitHub Pages, and its domain name is handled by Cloudflare. Like any web host, they may keep short-lived server logs (such as IP addresses) for security and reliability. Typefaces are loaded from Google Fonts, which receives your IP address when it serves them. See the GitHub privacy statement.

Offline reading

The site stores a copy of its own pages in your browser so it can open quickly and work offline. That copy stays on your device and is never sent to us.

Email

If you email us, we use your message and address only to reply. We do not run a mailing list at the moment.

A contact channel for privacy questions is coming soon.
