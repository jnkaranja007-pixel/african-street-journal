Le comité central du Frelimo doit statuer sur les élections internes et la déontologie

Le comité central du parti au pouvoir se réunit dans la province de Maputo pour examiner les propositions en vue de son 13e congrès, avant un code de conduite pour les membres.

Source : O Pais · 26 novembre 2026 · 1 min de lecture

Le parti au pouvoir au Mozambique, le Frelimo, tiendra une session extraordinaire de son comité central vendredi et samedi dans la province de Maputo. La réunion examinera les propositions formulées pour le 13e congrès du parti.

Le comité doit examiner les thèses proposées pour le congrès, une directive sur les élections internes du parti ainsi qu'un code de conduite et d'éthique pour les membres. Le porte-parole du parti, Pedro [...], a annoncé la session à Maputo jeudi.

L'annonce n'a pas fourni de précisions supplémentaires sur les propositions ni de date pour le congrès.

Pourquoi c'est importantLes membres du parti seront tenus par un nouveau code de conduite et éliront leurs dirigeants internes selon les règles approuvées par le comité ce week-end.
